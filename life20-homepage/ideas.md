## Idea A: "Architectural Minimalism" — 건축적 미니멀리즘

**Design Movement:** Swiss International Typographic Style + Contemporary Korean Minimalism

**Core Principles:**
1. 정보의 위계를 타이포그래피만으로 구현 — 색상보다 크기와 굵기로 강약 조절
2. 여백(Negative Space)을 적극적 디자인 요소로 활용
3. 수직/수평 그리드의 엄격한 준수로 신뢰감 형성
4. 텍스트와 이미지의 비대칭 배치로 시각적 긴장감 유지

**Color Philosophy:**
- Primary: Warm Charcoal `#2C2C2C` — 권위와 신뢰
- Secondary: Stone Grey `#8C8C8C` — 차분한 보조 정보
- Accent: Sage Green `#6B7C5C` — 이끼/자연을 상징하는 절제된 생명감
- Background: Off-White `#F5F3EF` — 따뜻한 중립
- Surface: Light Stone `#EBEBEB`

**Layout Paradigm:**
- 비대칭 2단 레이아웃: 좌측 좁은 컬럼(레이블/번호)+ 우측 넓은 컬럼(콘텐츠)
- 섹션 간 전환은 얇은 수평선(1px)으로만 구분
- 텍스트 블록과 이미지가 서로 겹치지 않고 정확히 정렬

**Signature Elements:**
1. 섹션 번호 레이블 (01, 02, 03) — 얇은 세리프체로 좌측 여백에 배치
2. 단어 하나를 극도로 크게 표시하는 "Statement Typography"
3. 이끼 녹색 얇은 수직선이 섹션을 구분

**Interaction Philosophy:**
- 스크롤 시 텍스트가 좌→우로 슬라이드인
- 호버 시 이미지 위에 텍스트 오버레이 페이드인
- 부드럽고 느린 트랜지션 (0.6s ease)

**Animation:**
- Intersection Observer 기반 순차적 페이드업
- 숫자 카운터 애니메이션 (통계 수치)
- 스크롤 진행 바 (상단 얇은 선)

**Typography System:**
- Display: Noto Serif KR (Bold 700) — 한국어 제목의 무게감
- Body: Noto Sans KR (Regular 400, Medium 500)
- Label: Noto Sans KR (Light 300, Letter-spacing 0.15em)
- 크기 비율: 72px / 48px / 32px / 20px / 16px / 14px

## Idea B: "Editorial Gravitas" — 에디토리얼 무게감

**Design Movement:** High-End Magazine Editorial + Nordic Sophistication

**Core Principles:**
1. 잡지 레이아웃처럼 텍스트와 이미지가 자유롭게 혼재하되 엄격한 베이스라인 그리드 준수
2. 대비(Contrast)를 극대화 — 매우 크거나 매우 작은 요소만 존재
3. 사진/이미지를 전면에 내세우되 흑백 또는 듀오톤 처리로 통일감
4. 긴 형식의 텍스트도 읽히는 타이포그래피 리듬

**Color Philosophy:**
- Background: Deep Slate `#1A1F2E` — 야간 하늘처럼 깊고 고요한 다크 베이스
- Primary Text: Warm Cream `#F0EBE0` — 따뜻한 대비
- Accent: Muted Olive `#7A8C5E` — 자연/이끼의 절제된 표현
- Highlight: Antique Gold `#C4A35A` — 프리미엄 강조
- Divider: `rgba(240,235,224,0.12)` — 거의 보이지 않는 경계

**Layout Paradigm:**
- 풀블리드(Full-bleed) 섹션과 좁은 컨테이너 섹션의 교차
- 텍스트가 이미지 위를 가로지르는 레이어드 레이아웃
- 불규칙한 그리드 (3-2-4 컬럼 변화)

**Signature Elements:**
1. 대형 배경 텍스트(Ghost Text) — 섹션 키워드를 반투명하게 배경에 배치
2. 듀오톤 처리된 이미지 (슬레이트 + 올리브)
3. 가로로 흐르는 마퀴 텍스트 (회사 키워드 반복)

**Interaction Philosophy:**
- 패럴랙스 스크롤링으로 깊이감 표현
- 카드 호버 시 이미지 확대 + 색상 변환
- 커서 커스터마이징 (작은 원형 커서)

**Animation:**
- 스크롤 트리거 클립패스 애니메이션 (이미지 reveal)
- 텍스트 마스크 애니메이션 (단어별 순차 등장)
- 부드러운 페이지 전환 효과

**Typography System:**
- Display: Playfair Display (Bold Italic) + Noto Serif KR
- Body: Source Serif 4 + Noto Sans KR
- Accent: DM Mono (숫자/코드성 데이터)
- 크기 비율: 96px / 64px / 40px / 24px / 18px / 14px

## Idea C: "Refined Materiality" — 세련된 물성감 ← **선택**

**Design Movement:** Contemporary Korean Craft + Bauhaus Functionalism

**Core Principles:**
1. 회색의 다양한 층위를 활용한 깊이감 — 단순한 회색이 아닌 따뜻한 회색 스펙트럼
2. 자연 소재(이끼, 나무, 돌)의 질감을 디지털로 번역
3. 정보 밀도와 여백의 균형 — 투자자와 시니어 모두 읽기 편안한 레이아웃
4. 한국적 미감(여백의 미)과 서구적 그리드 시스템의 융합

**Color Philosophy:**
- Background: Warm White `#FAF9F7` — 따뜻하고 고급스러운 베이스
- Surface: Stone `#F0EDE8` — 카드/섹션 배경
- Primary: Charcoal `#2A2A2A` — 주요 텍스트와 강조
- Secondary: Warm Grey `#6B6560` — 보조 텍스트
- Accent: Forest Sage `#4A6741` — 이끼/자연/성장을 상징 (브랜드 그린)
- Gold: Warm Bronze `#9B7B4A` — 프리미엄 포인트 (이막일장의 황금빛)
- Divider: `#E5E0D8` — 따뜻한 구분선

**Layout Paradigm:**
- 비대칭 오프셋 레이아웃: 섹션마다 좌우 정렬이 교차
- 스티키 사이드 레이블이 스크롤과 함께 이동
- 이미지와 텍스트가 서로 다른 속도로 스크롤 (패럴랙스)
- 넓은 마진(120px+)으로 고급스러운 인쇄물 느낌

**Signature Elements:**
1. 얇은 세리프 숫자 레이블 (01 / 02 / 03) — 섹션 인덱스
2. 이끼 텍스처 배경 패턴 — 특정 섹션의 배경에 미세한 유기적 패턴
3. 황금/청동 컬러 강조선 — 중요 인용구나 수치 옆의 수직선

**Interaction Philosophy:**
- 스크롤 시 요소들이 서로 다른 속도로 이동하며 깊이감 생성
- 카드 호버 시 미세한 상승 효과 (translateY -4px) + 그림자 강화
- 네비게이션 링크 호버 시 밑줄이 왼→오로 그어지는 효과

**Animation:**
- 스크롤 기반 페이드업 (opacity 0→1, translateY 24px→0)
- 숫자 카운터 애니메이션 (주요 통계)
- 이미지 패럴랙스 (스크롤 속도의 0.3배)
- 섹션 전환 시 배경색 부드럽게 변화

**Typography System:**
- Display (제목): Noto Serif KR Bold 700 — 한국어의 무게감과 전통성
- Subheading: Noto Serif KR SemiBold 600
- Body: Noto Sans KR Regular 400 — 가독성 최우선
- Label/Caption: Noto Sans KR Light 300, letter-spacing 0.12em
- English Accent: Cormorant Garamond Italic — 영문 서브타이틀에 우아함
- 크기 비율: 64px / 48px / 36px / 24px / 18px / 16px / 13px
